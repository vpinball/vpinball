This small document should give you a rough idea of what kind of values you should use for the physics settings of some of the VP elements. All values are just recommendations!
The "Scatter Angle" (basically the 'randomness' of physics interactions) is used in calculations together with the "Game Difficulty" (table Physics page, 0..100%, can be overridden by the player), so to have a better global control
for all elements, set the "Scatter Angle" of elements to 5 and limit the behavior/impact of the "Game Difficulty" by setting it to 10-20% or higher to control the overall gameplay difficulty.

Flipper Mass/Strength values below assume the 10.8 physics profile (flipper inertia modeled as a rod). With the 10.9 profile (table Physics page > Physics Profile),
the flipper inertia follows the flipper shape, so the swing speed differs; to keep the 10.8 swing, scale Strength by 3 * I_shape / r^2 (see PhysicsConstants.md).

Playfield:
----------
Gravity Constant   : 0.97 - 1.0
Playfield Friction : 0.075+       (This depends on how fast the ball should roll on the playfield. 
                                   EM tables are usually slower than modern tables. So for slower ball movements raise this value and/or modify the table slope)
Playfield Elasticity: 0.25


Flipper:
--------
Mass               : 1.0
Strength           : 1200-1800 (for EM tables) 2200-2800(for modern tables)
Elasticity         : 0.8
Elasticity Falloff : 0.43
Friction           : 0.5 or 0.6
Return Strength    : 0.058
Coil Ramp Up       : 2.4 - 3.5

Rubbers (default):
------------------
Elasticity         : 0.8
Elasticity Falloff : 0.4
Friction           : 0.5 - 0.6
Scatter Angle      : 5

Rubber for posts (the yellow or black kind):
--------------------------------------------
Elasticity         : 0.65 - 0.75
Friction           : 0.65
Scatter Angle      : 5

Walls as metal side walls:
--------------------------
Elasticity         : 0.3
Friction           : 0.15 - 0.3
Scatter Angle      : 5

Walls as metal wire/guides:
---------------------------
Elasticity         : 0.375 - 0.5
Friction           : 0.1 - 0.2
Scatter Angle      : 5

Walls as wood walls:
--------------------
Elasticity         : 0.375 - 0.425
Friction           : 0.2 - 0.3
Scatter Angle      : 5

Plastic drop targets:
---------------------
Elasticity         : 0.35 - 0.4
Friction           : 0.15
Scatter Angle      : 5

Stand-up metal targets:
-----------------------
Elasticity         : 0.3 - 0.35
Friction           : 0.15 - 0.25
Scatter Angle      : 5
