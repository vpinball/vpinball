# Assets

## fabian-hrir.sofa

Full-sphere head-related impulse responses (HRIRs) used by the binaural
spatial audio renderer (`src/audio/SpatialAudio.cpp`, loaded through
libspatialaudio / libmysofa).

Subset (424 positions, ~10 degree resolution) of the FABIAN HRTF database:

- Brinkmann, F., Dinakaran, M., Pelzer, R., Grosche, P., Voss, D., Weinzierl, S.
  (2020). "The FABIAN head-related transfer function data base".
  DOI: 10.14279/depositonce-5718.4
- Source file: FABIAN_HRIR_measured_HATO_0.sofa,
  https://sofacoustics.org/data/database/tu-berlin/
